# 楽天ROOM・楽天アフィリエイト スタート手順（2026-10-29 作成）

> ここに書いた登録手順は、2026-10-29 時点のネット上の解説記事をもとにしています。
> 画面や条件は変わることがあるので、最終的には楽天の公式ヘルプで確認してください。

## 今日やること（30〜60分）

### 1. アカウントを用意する（10分）
- [ ] 楽天会員（楽天ID）でログインできることを確認する
- [ ] スマホに **楽天ROOM アプリ** を入れ、楽天IDでログインする
- [ ] **ROOM URL** を決める（※一度決めると変更できないと解説されています。短く、ジャンルを限定しない名前がおすすめ）
- [ ] プロフィール文を入れる（下の例を参照）

プロフィール例（ジャンルは自分に合わせて変える）：
```text
30代・共働き｜実際に買ってよかった日用品と時短家電をのせています
気になる点も正直に書きます
※楽天アフィリエイトを利用しています
```

### 2. 楽天アフィリエイトを確認する（10分）
- [ ] 楽天アフィリエイトのサイトに同じ楽天IDでログインする
- [ ] マイページで、**報酬の受け取り方法** を確認する（楽天キャッシュなどで受け取る形と紹介されています）
- [ ] 楽天ROOMをリンク掲載先として **サイト情報に登録する必要があるか** を確認し、必要なら登録する
- [ ] 報酬率はジャンルで違う（一般に2〜4%と紹介されることが多い）。自分がのせたいジャンルの料率を料率表で確認する

### 3. 最初の5投稿を用意する（30分）
最初は **自分が実際に買って使った商品** だけをのせます。正直な感想が書けるので、表現の点検にも通りやすいです。

- [ ] 楽天市場の **購入履歴** を開き、使ってよかった商品を **5つ** 選ぶ
- [ ] 下の「商品メモ」を5つ分うめて、Claude に貼る
- [ ] 投稿案担当 → 点検担当 で投稿文を作り、合格した文をROOMに投稿する

商品メモ（1商品ごと）：
```text
商品名：
楽天の商品URL：
いつ・いくらで買った：
使ってどれくらい：
よかった点（具体的に。数字があると強い）：
気になった点（1つは必ず）：
どんな人に向いている：
写真：自分で撮ったものがある／ない
```

## 最初の2週間の進め方

| 時期 | やること | 担当 |
|---|---|---|
| 1日目（今日） | 登録・プロフィール・商品メモ5つ | あなた |
| 1〜2日目 | 5投稿を作成・点検・公開 | 投稿案担当 → 点検担当 → あなた |
| 3〜7日目 | 1日1〜3投稿。冒頭の型（失敗談／比較／数字）を変えて試す | 同上 |
| 公開1日後・7日後 | 数字を記録する | 結果追跡担当 |
| 14日目 | 何が反応よかったかを調べ、次のテーマを決める | 調査担当 |

数字の見かた：楽天アフィリエイトの成果レポート（クリック・成約・報酬）と、ROOMのいいね・コレ!を
「rakuten-tracker で記録して」と一緒に渡してください。

## 毎日のルーティン（15分）
1. 新しく買った物・使ってよかった物を1つ商品メモにする
2. 投稿案を作って点検し、合格した文を投稿する
3. 気になった人の投稿に「いいね」「コレ!」をする（ROOMは交流でフォロワーが増えやすいと言われています）

## やらないこと
- 使っていない商品を「使ってみた」と書く
- 「最安」「No.1」「絶対」「痩せる」などの表現（`knowledge/ng-expressions.md`）
- 時点を書かずに、価格・ポイント倍率をのせる
- 広告表記なしで、ブログやSNSにリンクを貼る
