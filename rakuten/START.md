# かんたんスタート

あなたがやるのは3つだけ。あとは Claude がやります。

1. **最初の1回だけ**：スマホに「楽天ROOM」アプリを入れて、楽天IDでログインする
2. **買ってよかった物を Claude に送る**：商品名と「よかったところ」を一言（スクショでもOK）
   → Claude が、そのまま貼れる投稿文を返します → アプリで貼って投稿
3. **1週間に1回**：ROOMや楽天アフィリエイトの数字の画面をスクショして Claude に送る
   → Claude が記録して、次にやることを教えます

※ パスワードは Claude に送らないでください。ログインと投稿ボタンはあなたが押します。
