# 使わない表現・注意する表現（点検担当が参照・追記）

| 表現 | 理由 | 言い換え例 |
|---|---|---|
| 最安・業界No.1・日本一 | 根拠を示せないと景品表示法の優良誤認・有利誤認になりうる | 「記事作成時点で〇〇円（楽天市場の商品ページで確認）」 |
| 絶対・必ず・100% | 断定表現 | 「〜しやすい」「私の場合は〜」 |
| 痩せる・治る・シミが消える | 健康食品・化粧品の効能効果は薬機法に触れうる | 使用感の範囲で書く（「つけ心地がさらっとしている」） |
| ポイント〇倍・〇円OFF（時点なし） | キャンペーンは終了・変動する | 「〇月〇日時点」「条件は商品ページで確認」と添える |
| 使ってみた（未使用品） | 事実と異なる | 「気になっている」「口コミでは〜」 |
| 広告表記なし | ステルスマーケティング規制（2023年10月〜） | 冒頭か末尾に「#PR」または「楽天アフィリエイトを利用しています」 |
