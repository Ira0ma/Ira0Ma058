# Amazonアソシエイト用 記事集

## フォルダ構成

- `articles/` … 公開用の記事
  - `mobile-battery-guide.md` … モバイルバッテリーの選び方（サンプル記事）
- `templates/` … 新しい記事を書くときのひな形
  - `buying-guide-template.md` … 「選び方＋おすすめ」型の記事テンプレート

## 公開前チェックリスト

- [ ] 記事の冒頭に **PR表記** と「Amazonのアソシエイトとして、当サイトは適格販売により収入を得ています。」を入れた
- [ ] 商品名・スペックは **Amazonの商品ページで自分で確認** して書いた
- [ ] **価格は書かない**（変動するため。書くなら「記事作成時点」と明記）
- [ ] リンクは **アソシエイト管理画面（SiteStripe等）で作ったもの** を使った
- [ ] 「最安」「No.1」など根拠のない表現を使っていない
- [ ] 実際に使った商品は、**自分の感想（良い点・気になる点）** を書き足した
- [ ] 使っていない商品を「使ってみた」と書いていない

## 売れる記事にするコツ

1. **「選び方」記事から始める**：「○○ おすすめ」「○○ 選び方」で検索する人は購入直前なので売れやすい
2. **結論を最初に書く**：比較表で答えを出すと離脱が減る
3. **用途別に分ける**：「毎日用」「旅行用」など、読者が自分ごとにできる分け方をする
4. **デメリットも書く**：正直なレビューほど信頼され、結果的にクリックされる
5. **リンクは3か所**：結論の直後、各商品の下、まとめの最後
6. **1ジャンルに絞って記事を増やす**：同じジャンルの記事同士をリンクでつなぐと、検索にも強くなる
