## 編集元
- lessons.json：全42レッスン。一意のIDは usdjpy-01 ～ usdjpy-42。
- title / summary / body / example / trap / takeaway の順で表示する設計。

- PDFとEPUB：静的な閲覧用。編集したアプリ版と差が出た場合は版を明示する。

## 重複整理
既存のFX用語集・経済用語集・ゴールド図鑑と意味を照合し、同じ説明を重ねて追加しない。
不足を既存項目へ統合するか参照リンクに置き換え、ドル円固有の例と注意点は残す。
common_pattern_refs は既存のゴールド初心者版パターンIDへの対応候補。
このIDがアプリ内に実在するか確認してからリンクし、そのままURLとして使わない。
新しい42項目を全部別ページにすることは要件ではない。42項目の知識に対応先を確保する。
この資料は共通70パターンのコピーではなく、ドル円の仕組みと使い方の入門書。

## 守ること
- 円高・円安、pipsとポイント、数量とロット、証拠金と最大損失を混同させない。
- 国内個人向け店頭FXの説明を、全業者・全商品に無条件で広げない。
- 数量計算はコスト・滑り前。実際の最小数量・取引単位は業者の条件で確認する。
- 指標発表時刻は固定せず、公式予定と夏時間を確認できる案内を残す。
- 為替介入の実施を価格や急落だけで断定しない。
- 売買予測、自動注文、パターン自動検出はこの資料に含まない。
- 外部フォント・CDN・分析用通信は追加しなくてよい。
- 既存の閲覧機能とUIへ自然に統合し、スマホ・iPad・PCで確認する。
- 資料の読み込みだけで、アプリを公開・デプロイしない。

## 計算練習
HTMLの sizing() / profit() が表示例。計算式は基本原理に基づく。
数量＝許容損失円÷（損切り幅pips×0.01）。刻み単位へ切り下げる。
買い損益＝（決済価格−新規価格）×ドル数量。
売り損益＝（新規価格−決済価格）×ドル数量。
空欄・ゼロ・負数・非有限値を検証する。実約定価格を使うとき、スプレッドを二重控除しない。
保存キーは usdjpy-book-v1-position。アプリに合わせて名前空間を管理する。
