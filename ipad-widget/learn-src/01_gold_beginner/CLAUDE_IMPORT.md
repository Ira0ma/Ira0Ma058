# 超初心者版の組み込みについて

このZIPを、旧版より優先する編集元として扱ってください。

- HTMLは全体の読書構成の参考です。PDFだけを編集元にしないでください。
- patterns-beginner.json に全70項目のやさしい説明と元の詳細条件があります。
- simple：ひと言でいうと／look：図のどこを見る／wait：次に何を待つ。
- level：まず覚える／少し慣れたら／あとで読む、の学習目安です。
- shape・confirm・caution は元の詳しい説明です。必須の成立条件を失わないでください。
- svg_file は対応図説です。SVGは模式図であり、厳密な比率を表すとは限りません。
- HTMLの冒頭6ページ、最後3ページは入門説明・練習・用語集です。統合時にも初心者向け導線を残してください。
- 元の項目IDを維持しています。既存用語集と意味を照合し、重複する説明は統合または参照し、知識を削除しないでください。
- 最初から70項目を読むことを求めず、まず8項目へ案内してください。
- 専門条件は段階的に開示し、やさしい説明を先に見せてください。
- 複雑な比率や波動は後回しにできますが、必要な定義は残してください。
- 同じ形でも出現位置や判定基準が異なる項目を、一括削除しないでください。
- PDFは超初心者版の固定レイアウトです。アプリ内で編集した場合は版の違いを明示してください。
- この資料に、売買ロジックの追加や公開・デプロイの指示は含みません。
