# 学習の本の編集場所

デスクの「学ぶ」パネルにある6冊のうち、4冊（ゴールド入門・パターン図鑑・ドル円入門・FVG詳説）はこのフォルダの外の `learn/` から読み込みます。

## 公開されるもの（learn/）
| ファイル | 中身 |
|---|---|
| `learn/gold.json` | ゴールド入門（元：はじめてのゴールド取引）。はじめに4・12章72レッスン・巻末9。超初心者の入口で、形はパターン図鑑、FVGはFVG詳説へ送る |
| `learn/pattern.json` | パターン図鑑（元：ゴールド超初心者版）。はじめに6・反転13・持ち合い13・ローソク足27・比率波動17・銘柄別2・練習用語2 |

| `learn/fvg.json` | FVG詳説（元：FVG専用版）。はじめに1・14項目・巻末2 |
| `learn/fig/{gold,pattern,usdjpy,fvg}/*.svg` | 図説（模式図）。文字を含めてSVGをそのまま編集できる |

本文を直すときは **learn/*.json を直接編集** します（以後の正本）。デスクは本を開いたときにだけ読み込みます。

### 1項目の形
```json
{ "id": "p38", "no": 38, "name": "強気の包み足", "aka": ["ブリッシュエンゴルフィング"], "yomi": "つよきのつつみあし",
  "level": "少し慣れたら",
  "simple": "ひと言でいうと", "look": "図のどこを見る", "wait": "次に何を待つ",
  "body": "説明（ドル円・FVG）", "example": "具体例", "trap": "よくある勘違い", "takeaway": "今日のひとこと",
  "diff": "似た形との違い", "more": [["形", "..."], ["成立の確認", "..."], ["注意", "..."]],
  "fig": { "src": "learn/fig/pattern/p38.svg", "alt": "図の説明" },
  "rel": ["fx:包み足", "pattern:p53"], "calc": "sizing" }
```
- 表示順は「ひと言 → 図 → 見る所／待つこと → 説明 → 具体例 → よくある勘違い → 違い → ひとこと → 計算 → くわしい判定メモ（開閉）→ 関連」。無い欄は出ません。
- `id` は変えないでください（関連リンク・ダッシュボードの「?」・しおりが使います）。
- `rel`（関連リンク）は `本:キー`。FX用語集・経済用語集は用語名（`fx:ネックライン`、章は `fx:ch:章名`）、学習の本は項目ID（`gold:gold-intro-50`、`gold:g-route`、`pattern:p01`、`usdjpy:usdjpy-31`、`fvg:fvg-10`）。
- `yomi` は索引の並び（漢字で始まる名前だけ必要）。
- `"guide": true` の項目は読み物ページ。`blocks` に `["p",文]`・`["h",見出し]`・`["ol",[...]]`・`["table",[見出し],[[行]]]`・`["note",文]`・`["fig",src,alt]`・`["links",[[ref,名前,説明]]]`・`["qa",[[問,答]]]` を並べます。索引には出ません。
- `calc`：ドル円は `"sizing"`（損切り幅から数量）・`"profit"`（損益）、ゴールドは `"goldsize"`（円／ドルの許容損失・予備枠・1ロットのオンス数・最小数量・刻み・必要証拠金率から数量。刻みで切り下げ、最小未満は「見送り」）・`"goldpnl"`（価格差×オンス−手数料±持ち越し、円換算は任意）。計算は `index.html` の `runCalc`／`runGold`、入力欄は `calcHtml`／`goldCalcHtml`。計算欄は「計算してみる」を開いたときだけ表示され、ブラウザ内だけで計算し、送信しません。
- ゴールド入門の数値（3,000ドル・150円・1ロット100オンス・証拠金率5％など）は計算例の仮定です。本文で固定値として書かないでください（pipの固定・レバレッジ25倍の適用・スプレッドの二重計上・税率・勝率・売買サイン・指標の固定時刻も書かない）。

## FX用語集・経済用語集
`index.html` の `GLOSSARY`・`ECONOMY`（今までどおり）。重なる項目には `rel` で学習の本へのリンクを付けています。

## 公開しないもの（learn-src/）
- `MAPPING.md`：元資料の全項目（ゴールド72＋70＋42＋14と導入・付録）の行き先と扱い（新規・統合・参照）
- 元資料のJSON・Markdown・HTML（参照用）。PDF・EPUBは取り込んでいません（アプリ版と表現が違う場合があります）
- `04_gold_introduction/`・`gold_build.py`：ゴールド入門の元資料と変換スクリプト（記録用。`yomi`・巻末の分割・計算欄・関連リンクの手直しは変換後に learn/gold.json へ直接入れたので、再実行すると消えます）
- `learn_build.py`：最初に元資料から learn/ を作ったときの変換スクリプト（記録用。再実行すると learn/ の手直しが上書きされます）
