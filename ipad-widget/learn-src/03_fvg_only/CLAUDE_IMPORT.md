# FVG専用版の組み込み

この資料を旧「FVGを読む。SVGで伝える。」の代わりに使用してください。
画像形式の説明は削除済みです。FVGの学習コンテンツのみを組み込んでください。

- 本文：lessons.json。固定IDはfvg-01～14。
- figure_fileが対応図説。編集可能なSVGファイルを画像素材として使用します。
- 旧版fvg-svg-02～15に対応し、fvg-01～14へ順に移行。旧版01と16～19は削除対象です。
- 既存アプリに旧版があれば、重複追加せず置換し、参照リンクや保存位置を必要に応じて移行してください。
- 導入・早見表・参考資料はfront-back-matter.json。
- 強気条件low3>high1、弱気条件high3<low1。等号は非成立。
- ヒゲ込み・3本目確定後で判定。中央・全埋め・無効条件を区別します。
- 取引ゼロや未約定注文の実在を図から断定しないでください。
- IFVGは役割転換候補。元のFVG失敗だけで逆向き有効としないでください。
- 図の境界・価格ラベル・本文の数値を一緒に修正してください。
- 既存のFVG解説と重複があれば統合・参照してください。
- 資料の読み込みだけで公開・デプロイ・自動注文を行わないでください。
